HTML Visual Editor

可视化 HTML 编辑工具。导入页面后可拖拽、对齐、改样式并导出结果。

可直接使用在线 HTML 版；同时提供 Windows 封装版 HtmlEditorLauncher.exe。
在线打开编辑器 下载 EXE 使用说明

在线版无需安装；EXE 适合本地双击使用。

为什么是 EXE？

产品逻辑原本写在 HTML 中。为避免源码被直接复制和改写，发布时封装成可执行文件，只保留使用入口。

快速开始

  1. 下载并双击运行 EXE
  2. 导入 HTML 文件或粘贴代码
  3. 进入 Edit Mode 编辑元素
  4. 完成后点击 Export 导出

HTML Visual Editor

Why EXE?

The product was originally implemented as HTML. Packaging it as an executable keeps the usable app while protecting the source.
