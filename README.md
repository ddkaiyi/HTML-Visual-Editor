# HTML Visual Editor

Desktop packages only. Download and run:

| Platform | File |
| --- | --- |
| Windows | [HtmlEditorLauncher.exe](./HtmlEditorLauncher.exe) |
| macOS | [HtmlEditorLauncher-macOS.zip](./HtmlEditorLauncher-macOS.zip) |

## Windows
Double-click `HtmlEditorLauncher.exe`.

## macOS
1. Download and unzip `HtmlEditorLauncher-macOS.zip`
2. Open `HtmlEditorLauncher.app`

If macOS blocks the app:

```bash
xattr -dr com.apple.quarantine ./HtmlEditorLauncher.app
open ./HtmlEditorLauncher.app
```
