Editor Guide
Follow the steps below to complete element selection, style editing, and page export faster.

1. Basic Workflow

  1. Import an HTML file first, or click "Import HTML Code".
  2. Switch to "Edit Mode", then click page elements to start editing.
  3. After editing, click "Export" at the top to save the result.

2. Selection & Navigation

  1. W Move to parent node, S move to child node.
  2. A/D Switch between sibling nodes.
  3. Esc Also move to parent node.
  4. Tab/Shift+Tab Move to previous/next sibling.

3. Editing

  1. Drag elements to change position; drag the bottom-right handle to resize.
  2. Use the right properties panel to adjust font, color, border, spacing, and transform.
  3. Double-click a text element for quick text editing.

4. Shortcuts

  1. Ctrl/Cmd+Z Undo，Ctrl/Cmd+Y Redo。
  2. Ctrl/Cmd+C duplicate selected elements.
  3. Ctrl/Cmd+D delete selected elements.
  4. Enter apply text box content (Shift+Enter for a new line).

5. Sync

  1. Select an element first, then click Add to Sync Stack。
  2. Then select another element of the same type (for example, both img or both div) and add it.
  3. When the sync stack has at least 2 elements, drag, arrow keys, and X/Y input will move them in sync.
  4. Remove Current removes a single element, and Clear Sync Stack resets the whole stack.
